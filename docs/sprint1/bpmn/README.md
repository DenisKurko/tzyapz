## Як відкрити файли

1. Відкрийте файл `models.drawio` у [draw.io](https://app.diagrams.net/) (File → Open → завантажте файл).
2. PNG-зображення (`models-M1.png` - `models-M4.png`) доступні для перегляду без додаткового ПЗ.
3. Для редагування використовуйте лише `.drawio`-файл; PNG генеруються з нього як експорт.

---

## Склад файлів

| Файл            | Зміст                                                         |
| --------------- | ------------------------------------------------------------- |
| `models.drawio` | Вихідний файл усіх BPMN-моделей (редагований)                 |
| `models-M1.png` | BPMN-модель M1 - Відкриття рахунку                             |
| `models-M2.png` | BPMN-модель M2 - Переказ коштів                                |
| `models-M3.png` | BPMN-модель M3 - Оформлення кредиту                             |
| `models-M4.png` | BPMN-модель M4 - Оплата рахунку                                 |
| `review.md`     | Протокол рецензування: модель → пункти чек-листу → виправлено |

---

## Нотація та конвенції

- Нотація: **BPMN 2.0**
- Іменування файлів: латиниця, без пробілів (`models-M1.png`, тощо)
- Кожна модель розміщена на окремому аркуші в `models.drawio`
- Експорт PNG виконується з роздільною здатністю не менше 150 dpi
